<h3>Accés a la base de dades:  </h3>

        <p>Accés a la base de dades fent servir un plugin del Visual Studio

        Code: <a href="https://marketplace.visualstudio.com/items?itemName=cweijan.vscode-database-client2">https://marketplace.visualstudio.com/items?itemName=cweijan.vscode-database-client2</a></p>


        <p>Cal que instal.leu aquesta extensió quan hagueu establert una connexió remota del Visual Studio cap a les màquines del

        laboratori cap al servidor.</p>

        

        <p>Les dades necessàries per realitzar la connexió son:</p>

        <p>Server Type: PostgreSQL</p>

        <p>Host: deic-docencia.uab.cat</p>

        <p>port: 5432</p>

        <p>UserName: st-c2</p>
